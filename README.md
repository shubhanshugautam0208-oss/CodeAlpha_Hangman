# CodeAlpha_Hangman

A simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Maximum 6 incorrect guesses
- Detects repeated guesses
- Displays correct and incorrect guesses
- Shows win and game-over messages
- Includes a play-again option

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Lists
- Strings
- User input

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or terminal.
4. Run:

```bash
python hangman.py
